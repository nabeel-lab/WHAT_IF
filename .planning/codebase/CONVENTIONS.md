# Conventions

- **Code Style**: Minimalist and highly readable.
- **Frontend Design**: Strictly professional, neutral colors (slate/gray) indicating an engineering platform. Avoids overly vibrant "cyber" tropes unless signaling verified metrics (green/amber).
- **Security**: Repositories are treated as untrusted. No dynamic execution is permitted during scanning.
- **Data Modeling**: All backend responses use strict `Pydantic` models.
